# Ruby Rebound

Full-colour Python 3 neon brick-shatter arcade for ElbowOS.

Control a neon paddle to rebound a glowing ball and shatter rows of colorful bricks. Catch falling orbs for bonus points. Combo streaks multiply the score.

A / D or Left / Right steer. R restart.

## Play

```bash
pip install -r requirements.txt
python3 ruby_rebound.py --play
```

## Record a 9:16 reel

```bash
python3 ruby_rebound.py --record
```

Outputs `RUBY_REBOUND_ElbowOS.mp4` (1080x1920, 15s, 30fps).
